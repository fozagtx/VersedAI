# Brand — VersedAI

Status: active

A learning studio for high-school students who want to use AI on real work, not sit through lectures. Warm paper, ink type, one violet mark.

## Direction

Soft consumer / editorial studio. Comfortable density. Flat sections with bordered cards. Display serif for the one italic word in the hero; plus-jakarta for UI; plex mono for kickers and XP.

## Palette

| Token | Hex | Role |
|---|---|---|
| background | `#F3EFE6` | Warm paper |
| foreground | `#1C1915` | Ink |
| card | `#FAF7F1` | Raised surface |
| muted | `#E8E2D6` | Quiet fill |
| muted-foreground | `#5C574E` | Secondary text (AA on paper) |
| border | `#DDD6C8` | Hairline |
| primary | `#6E54FF` | Brand mark, primary CTA only |
| success | `#2F6F45` | Done / complete |
| destructive | `#B42318` | Errors |

Do not add a second accent. Do not use purple gradients.

## Type

- UI / body: Plus Jakarta Sans
- Display italic: Instrument Serif
- Labels / XP / indexes: IBM Plex Mono

## Voice

Short. Direct. Age-appropriate. No “unleash”, “seamless”, or lecture-voice. Coach, don’t pitch.

## Motion

Spring for page sections. CSS for hover/press. Enter 250ms, exit 200ms. Honor `prefers-reduced-motion`.
